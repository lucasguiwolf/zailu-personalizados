# Zailu Personalizados — site estático

O site está em `docs/index.html` para preservar os arquivos existentes na raiz do repositório.

## Publicar com GitHub Pages
1. Abra Settings → Pages neste repositório.
2. Em Build and deployment, selecione Deploy from a branch.
3. Escolha a branch `main` e a pasta `/docs`, depois clique em Save.
4. Aguarde a publicação; o GitHub mostrará o endereço público nessa seção.

O catálogo usa valores a consultar e ilustrações provisórias. Substitua os emojis por fotos reais e confirme preços, prazo, personalização e entrega pelo WhatsApp. O número comercial está configurado como 5512981266819.
